# Image Describer
- Эта программа решает проблему отсутствия любых инструментов для описания изображений в Linux
## Зависимости

- Все зависимости указаны в файле dependencies.txt

### Использование
- Вы можете открыть графические настройки так:
```bash
./main.py -s
```
- После настройки можно задать сочитание клавиш в вашем окружении
- Обратите внимание что вызов 
```bash 
./main.py
```
Без аргументов запустит описание изображения всего экрана, а
```bash
./main.py -w
```
запустит описание активного окна
